# NOESIS — Intelligent Virtual Receptionist System

NOESIS is a production-grade AI Receptionist SaaS application designed to handle customer calls, respond to DMs, answer FAQs automatically, book appointments, and flag urgent requests 24/7.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Responsive SaaS UI)
* **Backend:** Python, FastAPI, REST APIs
* **Database:** PostgreSQL (Production) / SQLite (Local Development) via SQLAlchemy ORM
* **AI:** Google Gemini API
* **Voice:** Twilio Voice API & Browser Web Speech API
